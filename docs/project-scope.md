# Project Scope

## Purpose

Build a portfolio-quality mobile AI application that demonstrates a complete software system from user interface to machine-learning inference.

## MVP Includes

- mobile input form
- REST API
- validated request schema
- three-class sports outcome simulation
- synthetic ML training pipeline
- model persistence
- automated tests
- architecture and security documentation

## Out of Scope

The MVP intentionally excludes:

- real-money wagering
- sportsbook account integration
- deposits or withdrawals
- payment processing
- live odds execution
- claims of guaranteed prediction accuracy

## Future Enhancements

- historical sports-data ingestion
- PostgreSQL prediction history
- user accounts
- event/team search
- model metrics dashboard
- Docker deployment
- GitHub Actions CI
- cloud hosting
